# 🌊 LocalFlow — Deployment Steps

## ✅ Code is on GitHub
**Repo:** https://github.com/aadi15-blip/Tradie-ai-agent-business

---

## Step 1: Deploy Backend API → Railway (free)

1. Go to **https://railway.com**
2. Click **New Project** → **Deploy from GitHub repo**
3. Select `aadi15-blip/Tradie-ai-agent-business`
4. Railway auto-detects Python. Set start command:
   ```
   uvicorn main:app --host 0.0.0.0 --port $PORT
   ```
5. It'll give you a URL like `https://localflow-backend.up.railway.app`
6. **Copy this URL** — you'll need it for everything else

---

## Step 2: Deploy Dashboard → Vercel (free)

1. Go to **https://vercel.com**
2. Click **Add New** → **Project**
3. Import `aadi15-blip/Tradie-ai-agent-business`
4. Set **Root Directory** to `frontend/`
5. **Framework Preset** → Vite
6. Add environment variable:
   - `VITE_API_URL` = `https://your-railway-url.up.railway.app` (from Step 1)
7. Click **Deploy**

---

## Step 3: Deploy Signup Page → Netlify (free)

1. Go to **https://netlify.com**
2. Click **Add new site** → **Import existing project** → **Deploy with GitHub**
3. Select `aadi15-blip/Tradie-ai-agent-business`
4. Set **Base directory** to `signup/`
5. Set **Publish directory** to `.` (same as base)
6. Click **Deploy**
7. In site settings, change the **site name** to something like `localflow-signup`

---

## Step 4: Update the Widget URL

In the Railway backend, the widget serves at `/widget.js`. 
The tradie sites generated by the generator include:
```html
<script src="http://localhost:8200/widget.js?business_id=micks-roofing"></script>
```

When you deploy the backend to Railway, you need to update this URL in:
- `generator/generate-site.py` — change `http://localhost:8200` to `https://your-railway-url.up.railway.app`
- `widget/widget_builder.py` — same change

Then commit and push. Railway auto-redeploys.

---

## Step 5: Deploy Marketing Site → Netlify (free)

1. On Netlify, **Add new site** → **Deploy with GitHub**
2. Select the same repo
3. Set **Base directory** to `marketing/`
4. Deploy

---

## Step 6: Generate + Deploy Tradie Sites

When a tradie signs up, run:
```bash
python3 generator/generate-site.py --name "Mick's Roofing" --type roofing \
  --phone "1300 555 123" --areas "Parramatta,Hornsby" \
  --services "Roof Repair:550,Roof Replacement:8500"
```

Then upload the generated folder to Netlify as a new site, or to their own domain.

---

## Step 7: Buy a Domain

Get `localflow.com.au` (or similar) from GoDaddy or Namecheap (~$15/yr).
Point it at your Netlify marketing site.
